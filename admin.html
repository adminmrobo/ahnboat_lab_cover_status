콘텐츠 관리실

콘텐츠 내역(hub.csv)을 화면에서 바로 보고 고친 뒤 저장합니다. 기준일과 공개일로 카탈로그에 나오는 콘텐츠를 정합니다. 공지사항 탭에서는 홈페이지 맨 위 공지를 직접 씁니다.

콘텐츠 현황판공개 카탈로그표지 현황

관리자 비밀번호

비밀번호는 이 브라우저 안에서만 쓰이고 어디로도 보내지 않습니다. 콘텐츠 현황판(hub.html)·방문 레포트와 같은 관리자 비밀번호입니다.

처음 한 번만 — 저장용 GitHub 토큰 등록

비밀번호가 맞았습니다. 저장 버튼이 GitHub에 바로 올리려면 토큰이 한 번 필요합니다. 토큰은 비밀번호로 잠가 저장소에 data/admin_vault.enc로 두므로, 다음부터는 어느 기기에서든 비밀번호만 넣으면 됩니다.

토큰 없이 들어가도 보고 고치는 것은 똑같습니다. 저장을 누르면 잠긴 파일이 내려받아지고 GitHub 올리기 화면이 열리니, 그 파일을 끌어다 놓고 Commit changes만 누르면 됩니다.

한 번만 — 예전 관리자 키에서 새 비밀번호로 옮기기

내용 표가 아직 예전 관리자 키로 잠겨 있어 새 비밀번호로 열리지 않습니다. 예전 키를 한 번 넣으면 표·현황판·레포트 파일을 이 자리에서 새 비밀번호로 다시 잠가 저장소에 올립니다. 그 뒤로는 새 비밀번호만 씁니다.

새 저장소를 만들거나 표지를 바꿨나요? 하루 두 번(아침·저녁쯤) 저절로 가져오지만, 지금 바로 가져올 수도 있습니다.
