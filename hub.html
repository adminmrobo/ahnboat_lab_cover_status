콘텐츠 현황판

전체 표지 현황 주판봇 변환 상황 콘텐츠 현황판 공개 카탈로그

GitHub(adminmrobo)에 올린 콘텐츠와 GitHub 밖 실적을 한 표로 모은 DB입니다. 분류와 대상 여부는 data/hub.csv에서 사람이 정하고, 콘텐츠 존재 여부와 외국어팩·온톨로지 현황은 매일 오전 6시 수집 때 자동으로 채웁니다. 대분류 순서가 랩타운 지하 1층 서버실의 랙 순서이고, 공개 대상이면서 콘텐츠가 있는 항목만 서버실과 공개 카탈로그에 나옵니다.

    표 고치는 법 (엑셀)
    1. 저장소의 data/hub.csv를 내려받아 엑셀로 엽니다.
    2. 사람이 정하는 칸만 고칩니다: 제목, 주요내용, 대분류, 중분류, 소분류, 공개대상여부(Y/N), 연구실 시리즈·외국어팩·온톨로지 대상 여부(Y/N), 순서, 외부링크, 비고.
    3. 대분류 이름과 순서(=서버실 랙, 최대 10개)는 data/hub_meta.json에 있습니다. 새 대분류를 쓰려면 여기에도 추가해야 서버실·카탈로그에 나옵니다.
    4. CSV로 저장해 같은 이름으로 GitHub에 올리면, 다음 수집 때(또는 Actions에서 바로 실행하면) 현황판·서버실·카탈로그가 함께 바뀝니다.
    5. 새 저장소를 만들면 다음 수집 때 표 맨 아래에 미분류 · 검토로 자동 추가됩니다. 분류하고 공개대상여부를 Y로 바꾸면 공개됩니다.
    6. GitHub 밖 실적(논문·특허·저서·사업)은 저장소 칸에 외부:이름으로 적고 외부링크 칸에 주소나 번호를 넣습니다.
